## 🚀 Sobre o Projeto

Este repositório contém a minha versão do clone da interface da **HBO Max**. O objetivo foi aplicar na prática conceitos avançados de estilização, criando uma página moderna, responsiva e cheia de efeitos visuais.

O desafio consistiu em recriar o layout proposto pela instrutora **Michele Ambrosio**, focando puramente em CSS, sem o uso de frameworks (como Bootstrap ou Tailwind).

## 🛠️ Tecnologias e Conceitos Aplicados

Durante o desenvolvimento, foquei em dominar os seguintes tópicos:

* **Layout Moderno:** Uso intensivo de `Flexbox` e `CSS Grid`.
* **Animações:** Transições suaves no hover dos cards e animação de gradiente no cabeçalho.
* **Efeitos Visuais:** Uso de `Pseudo-elementos` (`::before`, `::after`) para overlays e degradês.
* **Transformações:** Efeitos de escala (`scale`) e rotação em elementos interativos.
* **Responsividade:** Media queries para garantir que o site funcione bem em celulares, tablets e desktops.
* **Customização:** Barra de rolagem (scrollbar) personalizada.

## 🎨 Modificações Pessoais

Além do proposto no desafio, busquei refinar:
- **Transições de Imagem:** Ajuste fino na opacidade dos cards para que a troca entre a imagem padrão e a imagem de "hover" seja extremamente suave (sem cortes bruscos).
- **Organização do Código:** Uso estratégico de variáveis CSS (`:root`) para facilitar a manutenção das cores e temas.
